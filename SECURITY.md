# Security Policy

## Scope

ECA-PQFA is a university research tool/reference implementation. It is not presented as a court-certified forensic system, HSM-backed product, or production security boundary.

## Reporting

Please report suspected security defects privately rather than publishing exploit details in a public issue.

Until a dedicated private security contact is configured, use a private GitHub security advisory or contact the repository maintainer through the GitHub account associated with this repository.

Include:
- affected commit or version;
- reproducible steps;
- expected versus actual behaviour;
- relevant logs with secrets removed.

## Sensitive data

Do not upload credentials, private signing keys, real forensic evidence, private PCAPs, personal data, or confidential Google Drive material to the public repository.

The repository intentionally uses synthetic research fixtures and configuration placeholders.
